# 1. The name

Date: 2026-11-10

## Status

Accepted

## Context

The tool needs a package name and a command. The Thoughtworks Technology Radar (vol. 35) names the practice "Agent suggestion
box"; people who have read it will search for that term.

## Decision

The package is `agent-suggestion-box`. The binary it installs is `suggestion-box`, so `npx agent-suggestion-box <command>` and,
once installed, `suggestion-box <command>` both work.

## Consequences

- The name says what it is and matches the radar's term.
- The binary is shorter than the package; the README shows both forms.
